关于 CKM - Codex Key Management 工具

CKM（Codex Key Management）是一款免费开源的 OpenAI Codex Token 格式转换工具，专为开发者和 AI 工程师设计。它支持多种主流 token 格式之间的互转，包括 CPA、sub2api、CockpitTools 和 EasyLLM。

主要功能

  • CPA 转 EasyLLM — 将 CPA 格式的 token 文件转换为 EasyLLM 备份格式
  • sub2api 转 CPA — 将 sub2api 代理配置导出为 CPA 格式的独立文件
  • CockpitTools 转 EasyLLM — 迁移 CockpitTools 数据到 EasyLLM 平台
  • EasyLLM 转 sub2api — 将 EasyLLM 备份导入 sub2api 代理配置
  • 批量转换 — 一次选择多个文件进行批量处理
  • 拖拽上传 — 直观的文件拖拽上传体验

支持的格式

CPA

每个账号独立 JSON 文件，可打包为 ZIP 批量下载

sub2api

API 代理配置格式，适用于 sub2api 代理服务

CockpitTools

Cockpit 工具使用的 token 格式

EasyLLM

EasyLLM 平台备份和恢复格式

为什么选择 CKM？

与需要上传到服务器的工具不同，CKM 所有处理均在浏览器本地完成。您的 token、access_token、refresh_token 等敏感信息不会离开您的设备，确保最大程度的安全性。同时支持 CPA 格式的批量文件打包为 ZIP 下载，提高工作效率。

使用场景

无论您是使用 sub2api 搭建 API 代理服务，还是使用 EasyLLM 进行 token 备份管理，或是需要在 CockpitTools 之间迁移数据，CKM 都能帮您快速完成格式转换。特别适合需要同时管理多个 OpenAI Codex 账号的开发者和团队。

常见问题 (FAQ)

CKM 是什么工具？
CKM（Codex Key Management）是一个免费开源的 OpenAI Codex Token 格式转换工具，支持 CPA、sub2api、CockpitTools、EasyLLM 格式之间的互转。所有转换均在浏览器本地完成，不会上传任何数据到服务器。
CKM 支持哪些格式？
CKM 支持四种 OpenAI Codex Token 格式：CPA（每个账号一个 JSON 文件，可打包为 ZIP）、sub2api（API 代理配置格式）、CockpitTools（Cockpit 工具格式）、EasyLLM（EasyLLM 备份格式）。
CKM 是否安全？我的数据会被上传到服务器吗？
完全安全。CKM 是一个纯前端工具，所有文件解析和格式转换均在您的浏览器本地完成，不会将任何数据上传到服务器。您的 token 和账号信息始终保留在本地。
如何将 CPA 格式转换为 EasyLLM 格式？
打开 CKM 工具，选择源格式为 CPA，选择目标格式为 EasyLLM，上传您的 CPA JSON 文件（支持多选），点击「执行转换」按钮即可。转换完成后点击下载按钮获取 EasyLLM 格式的 JSON 文件。
CKM 支持批量转换吗？
是的，CKM 支持批量转换。您可以一次选择多个 CPA 文件进行转换，也可以转换包含多个账号的 sub2api、CockpitTools 或 EasyLLM 文件。
